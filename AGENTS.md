# NullPhasor Engineering Instructions

## Identity
NullPhasor is a public engineering and experimentation
identity. It is separate from The Daktyrian Bureau.

## Project focus
- AI experiments
- Coding and software tools
- Interactive browser experiences
- Simulations and generators
- Experimental interfaces
- Public engineering portfolio projects

## Public repository discipline
- Assume every committed file can be read by anyone.
- Never include API keys, tokens, passwords, private data,
  private project files, or personal credentials.
- Inspect files before committing or publishing.
- Do not copy private Daktyrian material into this workspace.
- Document setup, usage, limitations and known issues.
- Make projects reproducible wherever practical.

## Engineering
- Primary environment: Android and Termux.
- Prefer lightweight HTML, CSS and JavaScript.
- Design mobile-first.
- Avoid unnecessary dependencies.
- Test actual functionality.
- Preserve working features.
- Explain architectural trade-offs.
- Never claim unperformed tests.

## Agent behaviour
- Inspect before modifying.
- Make incremental changes.
- Challenge weak ideas and unrealistic requirements.
- Ask before destructive operations.
- Report changed files, tests and limitations.
